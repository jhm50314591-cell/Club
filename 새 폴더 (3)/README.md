# 네온 클럽 (멀티플레이)

## 내 컴퓨터에서 테스트
    npm install
    npm start
브라우저 탭 두 개를 http://localhost:3000 으로 열어 보세요.

## 인터넷에 올리기 (Render 기준)
1. 이 폴더를 GitHub 저장소로 올립니다.
2. Render에서 New > Web Service > 저장소 선택
3. Build Command: `npm install` / Start Command: `npm start`
4. 배포가 끝나면 나오는 https 주소를 친구에게 보내면 끝.
(Railway, Fly.io도 같은 방식입니다. PORT는 서비스가 알아서 넣어 줍니다.)
